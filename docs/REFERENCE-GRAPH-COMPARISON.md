# Reference graph comparison and implementation

Inspected on 4 October 2026. Reference revision: `4709a0530f1a02f210101cec79746c824e8e41da` of [Robert McDermott's ai-knowledge-graph](https://github.com/robert-mcdermott/ai-knowledge-graph/tree/4709a0530f1a02f210101cec79746c824e8e41da). The [La Alhambra example](https://robert-mcdermott.github.io/ai-knowledge-graph/samples/la-alhambra.html) displayed 118 nodes, 185 relationships and 11 communities. This review covers source inspection and browser behavior; it does not measure relative extraction accuracy using identical documents and models.

## Assessment

The reference is better at presenting a network overview and has a broader command-line toolset. It is not uniformly better code for our research workflow. Evidence Atlas already provides stricter passage verification, research-specific types, editable graphs, original PDF inspection, multi-paper provenance and resumable browser work. Retaining those strengths while adapting the reference's explorer ideas offers more value than replacing our application with its Python pipeline.

The implementations below are written for our TypeScript/Cytoscape architecture. No Python, Jinja template, vendored vis-network code or extraction prompt was copied into this repository.

| Graph geometry       | Small nodes with labels outside the shape; node sizes combine degree, betweenness and eigenvector centrality.                            | Existing nodes reserve large shells for wrapped text. Groups are named after their leading concepts with no provider calls. This is a bounded single-level optimizer, not NetworkX's multi-level Louvain algorithm; partitions need not match his. Group IDs use normalized labels so JSON reimports do not depend on regenerated node IDs. |
| Controls             | Compact toolbar with overlays for communities, statistics and physics.                                                                   | Previously all layout/edit controls and entity types occupied rows above the graph. Added an Options disclosure, initially closed. It contains layout, physics, editing, appearance, filters, communities and path finding, with bounded internal scrolling. Search, navigation, image exports and theme remain immediately available.                                 |
| Labels and focus     | All, none or selection-only edge labels; neighborhood highlighting.                                                                      | Added all three modes. Node selection, search matches and paths reveal relevant connections. Clearing selection removes revealed labels. Labels remain attached to the actual curves; PNG and SVG reflect the selected mode.                                                                                                                                           |

Paths use only permitted nodes and edges. Communities and hub sizes describe the complete saved graph; changing visibility does not continually change its colors.                                                                                                      |
| Paths                | Shortest paths ignoring arrow direction, integrated with the details panel.                                                              | Added breadth-first traversal over visible relationships, highlighted routes and clickable evidence for each step. The UI explicitly states that direction is ignored and paths are navigation aids. It adds no relationships to the graph.                                                                                                                            |
| Portable HTML        | Bundles vis-network by default; optional shared library assets for hosted samples.                                                       | We already bundled Cytoscape and the same editable viewer. Redesigned HTML as a viewport-filling explorer with compact heading, collapsible metadata and JSON/edited-HTML downloads. Runtime, styling, evidence and settings remain embedded, and CSP forbids network connections. Original documents must still be reattached for offline PDF preview.                |
| Extraction           | Extracts typed SPO triples; source sentences are matched locally from entity names when available. Prompts encourage broad connectivity. | Our validators require a contiguous supplied quote and passage ID for every model edge. Research-specific categories and correlation/causation instructions are retained. A visually connected graph does not establish that its predicates are correct.                                                                                                               |
| Standardization      | Case/stop-word/plural normalization plus optional LLM merging.                                                                           | Our pipeline merges normalized names and explicit aliases. Aggressive plural/subset merging can collapse distinct measurements or biological identifiers; additional automatic merging was not introduced.                                                                                                                                                             |
| Inference            | Optional bridge, hub, within-component and taxonomy enrichment; caps the inferred fraction and records methods.                          | Our inferred edges still require source context and explanation. Replacing libraries would introduce migration work without addressing evidence or UI correctness.                                                                                                                           |

## User-facing behavior

Newly generated graphs start in the network view with community colors and selection-only connection labels. Existing saved graphs retain their shape and appearance. To switch an existing graph, open **Options → Customize → Network explorer**. Color grouping, label modes, inference visibility and the open/closed Options state are included in saved analyses and exports.

Community filters persist across export/reimport. Editing graph data recomputes communities and clears their filters and any active path so a changed group cannot remain unexpectedly hidden. Entity filters and confidence continue to apply. Custom per-node colors remain stored even while group colors are displayed; select Individual colors to see them again.

The options panel is a normal, keyboard-operable disclosure. It stays available in mobile and fullscreen views. Evidence inspection continues to use the existing draggable, viewport-clamped inspector and PDF preview. HTML downloads open directly from disk without a server.

## Verification

The new tests exercise separated structural clusters, isolates, duplicate/opposite-direction evidence, reordered input, disconnected paths, filtered routes and normalized imported settings. Browser checks cover dot sizing, external labels, overlap avoidance, selection labels, collapsed controls, source inspection, community filtering, standalone HTML reopening, edited HTML reopening and desktop/mobile canvas area. Existing tests now explicitly open Options before operating on controls placed inside it.

Final verification:

- `npm run build`: passed, including TypeScript and SEO checks. Vite reports the existing large bundled PDF/viewer assets.
- `npm test`: 148 tests passed across 14 files.
- `npm run format:check` and `git diff --check`: passed.
- Browser suite plus targeted reruns: 54 distinct scenarios passed; 15 optional corpus/OCR scenarios were skipped because their opt-in fixtures were unavailable. Explorer, spacing, editing, offline export, PDF inspection and ten-paper provenance checks passed.
- One broader homepage/setup viewport scenario remains failing. The untouched original revision was independently checked in `/private/tmp/evidence-atlas-baseline-20261004` and produced the identical failure: document height 907 px in a 900 px viewport. Its test and homepage layout were retained. This failure predates the graph work.
- An old ten-paper test asserted superseded billing copy; its assertion now checks the current `$0` app-fee statement. The sample-count assertion now includes the added community count. Tests for relocated controls explicitly open Options.

The portable example is saved locally as `output/evaluation/network-explorer/research-network.html`, with desktop/mobile screenshots alongside it. It contains the existing source-reviewed COVE sample, rendered in the new network view. Edited HTML was reopened with networking disabled and produced no external requests or browser errors.

Live AI extraction was not rerun: these changes concern deterministic rendering and exploration rather than model quality. The Alhambra sample and the COVE research sample are different graphs, so screenshots are UI illustrations rather than a controlled extraction benchmark.
